# WRENCHWORLD

Колони-сим про собственный автосервис. Rust Belt, 1988. Сборка v1 по диздоку «WRENCHWORLD — Game Design Document».

## Запуск

Двойной клик по `index.html`. Установка и сборка не нужны, сохранения лежат в браузере (автосейв каждое игровое утро + 3 слота).

## Управление

| Клавиша | Действие |
|---|---|
| Пробел | пауза |
| Q / W / E / R | скорость ×1 / ×8 / ×16 / ×32 |
| 1–9, 0, − | панели: Наряды, Машины, Люди, Рынок, Склад, Город, Стройка, Финансы, Гонки, Летопись, Цели |
| R (в режиме стройки) | повернуть объект; ПКМ — выйти из стройки |
| F | вся карта |
| Esc | закрыть панель / меню |
| ` или Ё | отладочное меню с читами (пароль 1234) |
| колёсико, перетаскивание | зум и сдвиг карты |

Новичку — сценарий «Школа Попса»: обучение ведёт по всем механикам и блокирует остальные кнопки, пока шаг не выполнен. Мини-игры покраски, ржавчины и рихтовки отключаются в настройках.

Наведи на цифру (время работы, цена, оценка машины, настроение) — увидишь разбор «почему?».

## Проверка

```bash
node tests/headless.js 30 honest
```

Остальные проверки:

| Команда | Что проверяет |
|---|---|
| `node tests/features.js` | эвакуатор, толкание, фургон, все четыре участка, миграция старого сейва |
| `node tests/roads.js` | езда только по дороге, место за местом запирает машину, снос колонки и щита, толкание в одиночку |
| `node tests/race.js` | сезон клубной серии из 8 этапов; подготовка решает сильнее случая |
| `node tests/clients.js` | точность диагностики от навыка, характеры клиентов, комплексные поломки |
| `sh tests/shot.sh out.png 'min:200,p:race'` | скриншот в headless Chrome (нужен запущенный сервер на 8765) |

Бот играет N дней без рендера. Аргументы: дни, стратегия (`honest`, `idle`, `flipper`, `boss`), сценарий (`legacy`, `jobless`, `heir`, `malaise`, `digital`), сид. Флаг `--log` печатает хронику.

## Структура

| Файл | Что внутри |
|---|---|
| `js/data.js` | defs: базовые узлы, симптомы, тесты, 35 моделей, черты, стройка, зоны, участки, клиенты |
| `js/data2.js` | 30 узлов, грейды деталей, кузовные панели, отходы и жидкости, контейнеры, миграция машин |
| `js/map.js` | карта по сетке: дороги, стены, крыша, зоны, грязь, объекты, участки, пути, стройка |
| `js/car.js` | экземпляр машины: генератор из сида, истина и знание, ржавчина, цена |
| `js/sim.js` | время, деньги, движение машин, сутки, тревоги, сейвы |
| `js/pawns.js` | люди: A*, выбор работы, T_fact, Q, настроение |
| `js/orders.js` | клиенты и заказ-наряды |
| `js/market.js` | объявления, торг, аукцион, продажа, город |
| `js/race.js` | клубная серия: календарь, сетап, трейлер, живой заезд, спонсоры |
| `js/events.js` | рассказчик, цели, достижения |
| `js/waste.js` | старые детали, мусор по видам, вывоз, сливы жидкостей, экоштрафы |
| `js/body.js` | кузовные панели и работы, мини-игры, поиск б/у по телефону |
| `js/city.js`, `cityui.js` | генератор города, соседи, машины жителей, поездки сотрудников |
| `js/tutorial.js` | сценарий-обучение «Школа Попса» |
| `js/ui3.js` | чертёж в 5 проекциях со слоями, кузовные работы, мини-игры, отладочное меню |
| `js/render.js`, `ui.js`, `ui2.js`, `modals.js`, `audio.js`, `main.js` | рендер, интерфейс, звук, цикл |
| `docs/` | журнал решений, прогресс, запросы к человеку |

Симуляция (`data`–`events`) не знает про DOM и грузится в Node.
